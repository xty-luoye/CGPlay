# CGPlay 1.0.7.15 更新说明

发布日期：2026-10-13

本版修复 EXR 图片序列以非零帧号起始时的时间显示和相对帧定位问题。

- 修复 `shot.0101.exr` 这类序列首帧被显示成绝对时间（例如 `00:00:04:05`）的问题；首帧现在从 `00:00:00:00` 开始。
- 统一播放、逐帧、时间线点击、入点/出点循环和缓存预读使用相对于当前序列的帧号。
- 保留 tlRender 内部的绝对源时间，跳转时正确映射回文件序列的起始帧，避免非零起始序列错位。
- 增加 0、101、1001 起始帧及 23.976/24/30 FPS 的后台时间契约检查。

安装包：Windows x64 Full。源码许可证：GPL-3.0-only；第三方组件保持原许可证。
