# CGPlay 1.0.7.16 更新说明

发布日期：2026-10-13

本版集中修复切源状态、EXR 颜色与时间显示，以及字幕异步任务的状态串用问题。

- 修复切换文件后旧 A/B 入出点仍限制新文件播放的问题。
- 修复倍速和循环按钮与实际播放状态不一致的问题；在同一播放器窗口切源时保留倍速和循环选择，并按新文件帧率正确应用。
- 修复快速从 EXR 切到视频或关闭文件后，旧颜色回调再次影响画面的问题。
- 统一播放栏、查看器和时间线的时间码显示，修复分数帧率下的显示偏差，并覆盖 1 FPS 与非零起始帧序列。
- 修复切源或重新打开同一文件后，旧字幕任务、延迟续跑和重试影响新会话的问题。
- 整理全屏和字幕状态管理，减少主窗口中的重复逻辑，并补充实际切源、播放和延迟回调回归测试。

继续保留全屏浮层控制条、F11/空格控制、AI 工作台默认关闭和 GitHub 自动更新。

## 下载与安装

- Windows x64 完整版：[CGPlay_Setup_1.0.7.16_full.exe](https://github.com/xty-luoye/CGPlay/releases/download/v1.0.7.16/CGPlay_Setup_1.0.7.16_full.exe)
- 安装前关闭 CGPlay 和 QuickLook，安装后在“帮助 → 关于 CGPlay”确认版本为 1.0.7.16。
- 1.0.7.12 及以上版本可通过内置更新入口获取新版；更早版本建议手动下载安装。
- 完整包包含运行组件；云端 AI 仍需自己的账户、API 或模型配置。
