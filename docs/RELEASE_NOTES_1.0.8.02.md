# CGPlay 1.0.8.02 · Windows x64

已有播放器可在应用内检查更新。也可直接[下载 Windows x64 在线安装程序](https://github.com/xty-luoye/CGPlay/releases/download/v1.0.8.02/CGPlay_Setup_1.0.8.02_full.exe)。从 1.0.8.01 升级时，下载约 45.3 MiB 即包含所有变更。首次安装或从 1.0.8 升级时，安装程序还会从 GitHub 获取并校验 1.0.8.01 的基础安装包。将官方基础安装包放在在线安装程序旁也可复用。

手动覆盖仍适用于 1.0.8.01 完整版。退出 CGPlay 和 QuickLook，将 [增量 ZIP](https://github.com/xty-luoye/CGPlay/releases/download/v1.0.8.02/CGPlay_Update_1.0.8.01_to_1.0.8.02_win64.zip) 中的三个文件覆盖到原安装目录。

## 播放与打开速度

- 长视频按播放位置和方向安排音频预读，保留已解码缓存，减少打开或远距离跳转后后台音频与画面解码争抢资源。
- 改善高分辨率、高帧率视频播放。连续存储的 YUV 420 图像按整块平面复制，减少逐行复制开销。
- 重复打开视频时，时间线缩略图全部命中磁盘缓存即可直接显示，省去重复探测和解码。缓存缺失时沿用短片批量提取、长片按采样位置读取的方式。
- 适配 4K 高帧率 10-bit HEVC 和部分 8K HEVC 缩略图的 CUDA 解码。硬件不可用时回退到软件解码，同一长片缩略图任务只尝试一次失败的硬件路径。

## 播放列表、文件格式与色彩

- 文件成功打开后才新增或选中播放列表条目。损坏的 MP4 打开失败时不会留下无效条目；已有条目在确实打开后更新媒体信息。
- 支持直接打开有效的 VP9 IVF 文件。
- 修复窗口与全屏切换时恰好没有解码画面、导致适应窗口比例突变的问题，涉及 Theora OGV 等素材。
- 修复从普通视频切到 EXR，再切回视频时，用户原先选择的 OCIO 输入色彩空间无法恢复的问题；一并恢复切换前的配置、显示与视图。
- 多视频轨文件的封面、时间线缩略图、分辨率与帧率跟随实际播放视频轨，避免误取附带封面或其他视频轨。

## 字幕、图像序列与验证

- 字幕生成期间关闭窗口时，先取消任务，等待后台任务收尾后再关闭窗口。
- 修复文件名带方括号时图像序列或同名多语言外挂字幕匹配失败的问题；只把实际文件作为字幕候选，避免把同名目录当成字幕。
- 增加对缩略图缓存、硬解回退和多视频轨的回归覆盖。性能测试可按目标源帧核对首帧、跳转等待和实际出帧。
- 源码同时保留开发文件夹版的高帧率预缓冲、片头请求排序及无音频素材打开优化。正式版沿用 1.0.8.01 的 Qt 6.11.3 和 tlRender 0.27.1，引擎适配补丁随本版源码提供。

## 正式包验证与文件清单

测试使用 1.0.8.01 正式安装目录副本，仅覆盖本次 ZIP 中的文件。在本机，4K60 和 8K60 短片分别实际画出约 57.2 和 54.5 帧/秒。另一段 65 分钟 4K60 HEVC/AAC 测试片由短素材循环封装，共 23.4 万帧；从片头跳到 40:03，目标画面在 498 毫秒后出现，随后连续播放约 30 秒，平均每秒画出 59.8 个不同源帧。这些是后台渲染实测值，具体表现取决于素材和硬件。
