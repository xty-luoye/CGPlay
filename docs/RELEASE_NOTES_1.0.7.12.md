# CGPlay 1.0.7.12 更新说明

发布日期：2026-10-08

## 播放与全屏

- 修复播放中进入全屏时的明显停顿：移除固定的暂停绘制等待，合并重复重绘。
- 保留上一版本的缩放稳定性修复，改善全屏进出、最大化恢复及快速连续切换的体验。

## AI 工作台

- AI 工作台和 Codex 工作台启动时默认关闭，需要时从“视图”菜单打开。
- 界面按需加载；旧布局不会在启动后重新弹出工作台，快速打开后关闭也不会反弹。

## AI 接口与模型

- 更新 OpenAI Responses / Chat Completions、DeepSeek、Qwen / DashScope、Gemini、Anthropic 等现有接入路线的兼容处理。
- 改善推理模型的输出参数、服务端模型列表及分页处理；支持手动填写模型 ID，保留用户明确选择的模型。
- 修复 Gemini 切换模型后仍请求旧模型地址的问题，并过滤内部思考片段。
- 改善连接验证和错误提示，避免无效响应被当成连接成功。

模型是否可用取决于服务商、账户权限和所选模型能力。此次更新不包含 API Key、云端模型或调用额度；协议验证使用本地模拟服务，未代用户调用付费模型。

## 自动更新

- 默认在启动后后台检查 GitHub 最新正式版，持续运行期间每天检查一次。
- 发现新版后在状态栏提示，点击即可查看更新说明和下载；也可从“帮助 → 检查版本更新”手动检查。
- 后台下载支持取消，安装前核对安装包大小和 SHA-256；校验失败时不会安装。
- 下载完成后选择“关闭并安装”，播放器退出后启动安装程序；也可稍后手动安装。
- 可在设置的“软件维护”区域关闭自动检查。

**旧版升级提示：** 1.0.7.11 及更早版本仍可能读取旧更新镜像。请先手动安装一次 1.0.7.12，此后使用新的 GitHub 自动更新通道。旧组件检查和下载机制仍独立工作。

## 安装与源码

- 本次提供 Windows x64 Full 完整安装包，以及 SHA256SUMS.txt。
- 源码与本版标签一同发布，按 GPL-3.0-only 开源；第三方组件保持原许可证。
- 安装包尚未签名。源码的第三方构建环境限制见 [构建说明](OFFICIAL_BUILD.md)。
