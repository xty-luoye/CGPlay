# CGPlay 1.0.7.18 更新说明

发布日期：2026-10-15

本版集中修复 EXR 导出、会话恢复和播放列表的六项已确认问题，并补齐相邻的 OTIO 导出和会话保存边界。

- 修复 EXR 序列导出选取片段错误：文件编号从 1001 等非零值开始时，按播放器中选择的范围导出，批注跟随对应画面；无效范围明确报错。
- 修复带 Z 等额外通道的 EXR 被误当作透明画面：按通道名称识别 RGB 和真实 Alpha，没有 Alpha 时保持不透明；无法明确识别的通道组合停止导出并提示。
- 修复恢复会话后 A/B 入出点和播放位置丢失：等待目标媒体加载完成后恢复，切换文件会取消过期恢复；加载失败时保留恢复快照。
- 优化播放列表批量导入和恢复：文件信息在后台排队读取，条目顺序保持稳定，删除或清空列表后不再回填过期结果；信息未就绪时禁止错误导出 OTIO，保存会话也不会写入临时帧率。
- 优化缩略图调度：限制同时派发的缩略图任务，减少对媒体加载等共享后台任务的占用。
- 优化图像序列导出：复用已读取的首帧，避免一次重复解码和色彩处理。
- 修复 OTIO 导出接口兼容问题，避免生成无效内容；导出失败时给出明确提示。

## 使用说明

- 播放器导出范围仍从 0 开始计数，与时间线位置一致。比如磁盘文件 `render.1001.exr` 至 `render.1003.exr`，选择 `1..1` 导出第二帧。
- 命令行导出保留按磁盘帧号选范围的原有用法；新增 `--relative-frames` 可按播放器的相对位置选范围。
- EXR 支持明确的单一 RGB 通道组，以及同组的真实 Alpha。没有通道选择界面的多 RGB 层、多 part 或仅数据通道素材会明确拒绝导出，避免猜测内容。此项不代表新增通用 AOV 导出或修改 OCIO 色彩变换。
- 视频播放、I/O 设置 A/B 入出点及正常切源清空入出点的用法保持一致。

## 下载与安装

- Windows x64 完整版：[CGPlay_Setup_1.0.7.18_full.exe](https://github.com/xty-luoye/CGPlay/releases/download/v1.0.7.18/CGPlay_Setup_1.0.7.18_full.exe)
- 安装前关闭 CGPlay 和 QuickLook，安装后在“帮助 → 关于 CGPlay”确认 1.0.7.18。
- 1.0.7.12 及以上版本可通过内置更新入口获取新版，更早版本建议手动下载安装。
- 完整版包含运行组件；云端 AI 仍需自己的账户、API 或模型配置。
