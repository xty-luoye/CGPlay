# CGPlay 1.0.8 更新说明

适用版本：1.0.8。

本版增加 A/B 合成视频导出和录屏，并集中修复导出、缓存与异步任务中的问题。

- **A/B 合成导出**：将当前横排、竖排、划像、叠加或差异对比保存为一个视频；可选 A、B 或无音轨，支持 H.264、H.265 和 ProRes HQ。按 A 的时间范围与帧率输出，B 按实际时间戳取帧。
- **录屏**：从“窗口 → 录屏…”打开，默认录制整个桌面／显示器；单显示器自动选中，多显示器可选来源，也可切换到指定窗口或播放器区域，按需加入系统声音和麦克风，分别调整音量和静音。可选原始分辨率、720p、1080p、2K、4K、8K，帧率最高 120 FPS，并显示实际编码帧率及跳帧数。支持暂停、继续和停止保存；修复高规格录制停止时提前释放编码输出的收尾竞态；录制先写可恢复的 MKV，正常结束后保存为 MP4，异常时保留录像和恢复记录。
- **导出更安全**：导出完成后才提交目标文件；取消、编码失败或关窗会清理暂存文件，防止覆盖源媒体、序列成员和旧结果。普通导出与 A/B 导出共用任务保护，避免重复启动。
- **色彩与精度修复**：导出使用当前查看设置的色彩快照，修复普通 sRGB 图片被错误套用线性变换等问题；明确区分 RGB、真实 Alpha 与数据通道。ProRes HQ 保留高位深路径；无法正确表示的配置明确提示。
- **缓存设置生效**：内存预算和读取范围应用到实际播放器，按素材帧率换算；新增缩略图磁盘缓存位置、容量和使用量设置，后台清理本软件生成的缓存文件。
- **界面响应优化**：系统性能采样移至后台，减少暂停和隐藏画面的显示轮询；切源、逐帧和恢复显示会及时唤醒。修正批注帧率、任务释放和缓存缩略图并发写入问题。
- **全屏播放修复**：修复从最大化窗口退出全屏后，窗口刷新未恢复而导致画面停住的问题，保持播放状态及空格暂停、继续操作。
- **组件更新更稳妥**：更新组件时，已启动的字幕、导出等后台任务继续使用原有运行环境，避免任务执行到一半时文件被替换。
- **状态更准确**：尚未实现的硬件解码能力如实显示为软件解码；未实际测量的响度不再显示模拟数值。

## 使用提示

录屏首次使用需要允许系统对应的屏幕、窗口或声音设备访问。当前录屏面向 SDR，输出为 H.264/AAC，最高 8K / 120 FPS。原始分辨率按所选捕获区域的实际像素输出，宽度向上补齐到 4 的倍数、高度向上补齐到偶数。当前使用 CPU 编码，实际流畅度取决于设备性能，可根据面板的编码帧率和跳帧数调整档位；不包含 OBS 的直播、游戏注入、摄像头场景编排或插件管理。录制播放器时，字幕、批注和浮层会一并录入；切全屏或跨不同缩放比例的屏幕导致来源尺寸改变时，会停止并保留录像，请重新开始。

A/B 导出要求 A、B 已成功加载；超出 B 有效时间的部分显示黑帧。未被导出路径完整支持的自定义 LUT、数据通道或颜色配置会明确报错，不猜测转换。EXR 多层、多 part 和 deep 素材不代表获得通用 AOV 导出支持。

整屏模式录制所选显示器上的所有应用，切换应用或最小化 CGPlay 后仍可继续。已完成一次本地静音整屏短测：3440×1440、30 FPS、约 5 秒，播放器最小化约 3 秒后恢复，录像持续写入。后台自动验收使用合成画面和测试音频；真实系统声音、麦克风及持续 8K / 120 FPS 的设备性能仍未验证。
