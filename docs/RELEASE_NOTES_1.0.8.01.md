# CGPlay 1.0.8.01

本次更新改进播放器的键盘操作、快进后退、拖入视频和进度显示。

- 打开视频后即可用空格暂停或继续、左右方向键快进或后退，无需先用鼠标点击画面。输入框和弹出菜单仍保留各自的键盘操作。
- 左右方向键默认跳转 5 秒，可切换为按帧或按秒跳转，并选择 1、5、10 的步长。播放时跳转后保持播放，暂停时保持暂停。
- 上下方向键调节音量，每次增减 5%。
- 点击底部进度读数可切换帧/时间码与秒数显示，并保存选择；改善时间轴两端和底部进度文字显示不全的问题。
- 直接拖入新视频会加入侧边播放列表并切换播放；重复文件不会重复加入。分屏对比按需开启，再自行选择对比视频。
- 改善快速切换对比视频，以及循环播放时跳转到视频边界附近的行为。

Windows 64 位完整安装包：`CGPlay_Setup_1.0.8.01_full.exe`。

同时提供组件更新文件、校验清单和对应源码。本版源码更新包复用 1.0.8 的依赖源码，请按源码说明和索引获取所需文件；已有且校验一致的依赖文件无需重复下载。
