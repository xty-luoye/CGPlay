更新日期：2026-10-25

本文面向 Windows 完整版 1.0.8 用户。为保留已有链接，文档文件名仍沿用 1.0.7。

2. 核心定位

CGPlay 面向动画、影视、VFX、合成及字幕审看，提供播放、逐帧检查、A/B 对比、批注、播放列表、OTIO、OCIO、视频导出和 AI 工作台。

适合检查镜头版本、记录逐帧反馈、制作审片视频与批注报告。复杂素材的兼容性以实际编码和文件结构为准。

3. 播放与媒体支持

常见输入包括 EXR、DPX、TIFF、PNG、JPG 图像及序列，以及 MOV、MP4、MXF、MKV、AVI、WebM 等视频容器。扩展名不代表其中所有编码均可播放。

播放操作

  • “文件 → 打开...”或拖入素材。
  • Space 播放 / 暂停；J、K、L 分别倒放、停止、正放。
  • Left / Right 上一帧 / 下一帧；Shift+Left / Shift+Right 后退 / 前进 10 帧。
  • Home / End 跳到开头 / 结尾。
  • I / O 设置 A（入点）/ B（出点），Alt+I / Alt+O 清除；A 早于 B 时循环播放该区间。时间轴左下显示 A/B 时间码，长视频中的短区间也能确认。播放列表、视频画面和全屏中均可打点；文本框有焦点时保留正常输入。
  • 播放栏可调整倍速、音量和静音。“音频 → 设备...”用于选择可用音频设备。
  • 状态栏可查看帧、FPS、分辨率、编码、缩放和 OCIO 状态。

图片序列

将同一镜头、同一命名规则的连续帧放在同一文件夹，例如 shot.0001.exr、shot.0002.exr。打开其中一帧，按提示确认序列帧率；应与制作时的帧率一致。

遇到缺帧、异常编号或损坏帧时，先检查源文件；成功打开首帧不代表整段序列已完整。EXR 色彩和 AOV 注意事项见第 8 节。

4. 视图与窗口

  • 鼠标滚轮缩放；F 适应窗口；1 切换 1:1 像素显示；+ / - 放大 / 缩小。
  • 按住鼠标中键拖动，或 Alt+鼠标左键拖动，平移画面。
  • F11 进入 / 退出全屏，Esc 也可退出。全屏时移动鼠标可滑出底部控制条，停留片刻后自动收起；控制条覆盖在视频上方，不改变画面大小。空格切换播放/暂停，支持自定义快捷键。
  • “视图”菜单可控制左右面板、批注工具、对比工具栏和工作台。
  • “窗口 → 新建窗口”可打开另一播放器窗口。

设置与自定义

“视图 → 自定义工作区”（Ctrl+Alt+W）打开设置。可按分类浏览，也可搜索“快捷键”“缓存”“字幕”等功能；设置搜索框支持 Ctrl+F。

在“快捷键”页录入并保存，或点击“恢复默认快捷键”。调整工作区后可用“视图 → 保存工作区”保存，也可“恢复默认工作区”。本文快捷键按默认配置编写，自定义后以菜单和设置页为准。

5. 播放列表与 Shot 管理

  • 拖入多个文件加入播放列表，点击 Shot 卡片切换镜头。
  • 卡片用于查看缩略图、文件名、分辨率、帧率、时长等信息。
  • 可搜索素材、标记审片状态，并把素材指定为 A/B 对比源。
  • “OTIO → 导入 OTIO...” / “导出 OTIO...”用于时间线交换。相关媒体仍需在当前电脑可访问，不保证还原剪辑软件中的全部特效。

保存批注与保存会话是不同操作：“文件 → 保存批注...”记录当前媒体批注，“文件 → 保存会话”保存会话。

6. A/B 对比

先打开 A 版本，再在播放列表或对比区域指定 B 版本；从“视图 → 对比工具栏”显示控制栏。

模式 默认快捷键 用途
A A 查看 A 源
B B 切换 B 源显示
Wipe W 划像对比
Overlay N 叠加对比
Difference D 差异对比
Horizontal H 水平分割
Vertical V 垂直分割
Tile T 平铺

按模式调整划像位置、角度或叠加比例。Ctrl+Shift+C 切换自动清除 B 源。比较前核对两段素材的帧率、范围和对应内容，避免把不同时间点的画面误当作版本差异。

7. 批注与审片

从“视图 → 批注工具”显示工具栏，定位到需要反馈的帧，再选择箭头、矩形、圆形、文字、自由绘制或点标记。批注绑定到具体帧，Review 面板可浏览并跳转。

  • Alt+S 选择，Alt+A 箭头，Alt+R 矩形，Alt+C 圆形，Alt+T 文字，Alt+D 自由绘制。
  • Delete 删除选中批注，Ctrl+Z / Ctrl+Y 撤销 / 重做。
  • Ctrl+S 或“文件 → 保存批注...”保存；“文件 → 加载批注...”读取已有 .review.json。
  • 可从“文件 → 导出”输出 JSON、HTML 审片报告或带批注视频。导出批注报告前确认当前已有批注。

8. EXR、Alpha 与色彩管理

“颜色 → OCIO 设置...”或查看器顶部 LUT 按钮打开设置；顶部 OCIO 按钮和“颜色 → 启用 OCIO”控制色彩管理开关。

  • 可使用内置 ACES 配置或外部 .ocio 配置，并选择输入色彩空间、显示与视图。
  • EXR 会走线性图像的显示处理。输入空间应与实际制作空间一致，不能仅因文件是 EXR 就认定它必然是 ACEScg。
  • 曝光和伽马用于审看；“颜色 → 查看 Alpha 通道”用于检查透明度。
  • 外部 OCIO 配置引用的 LUT 等文件也需可访问。配置、空间或视图不可用时，先处理提示再判断颜色。
  • RGB / RGBA 是颜色图像；Z、法线 N、velocity、ID 等 AOV 是数据，不应按普通 RGB 解释或随意应用显示变换。
  • 本说明不承诺任意多层、多 part EXR 的 AOV 选择与无损导出。交付指定 AOV 前，先在制作软件中确认通道含义，整理为明确的 RGB / RGBA 审看片段；保留原始 EXR 作为数据交付。

显示和视频导出可能经过不同处理路径。正式交付前先导出短片段，核对输入空间、曝光、Alpha 及目标播放器中的颜色；界面显示效果不等于所有导出路径都完全一致。

9. 导出功能

“文件 → 导出”提供 JSON、HTML、普通视频、A/B 对比视频和带批注视频。“文件 → 渲染当前范围...”为另一个渲染入口；OTIO 位于独立菜单。

视频导出步骤

  1. 打开素材，确认要输出的镜头和批注。
  2. 选择“文件 → 导出 → 导出视频...”或“导出带批注视频...”。
  3. 按用途选择 H.264 / H.265（MP4）、ProRes 422 HQ 或 ProRes 4444 + Alpha（MOV），选择保存位置。
  4. 确认输出帧率；界面中 0 表示自动检测。图片序列应核对制作帧率。
  5. 输入起始帧和结束帧。播放器导出的起始帧从 0 开始，结束帧包含在输出中；序列同样使用相对位置，磁盘文件从 1001 开始时，范围 1..1 表示导出第二帧。此入口单独询问范围，不要假定播放入点 / 出点已自动成为导出范围。
  6. 等待成功提示；可在进度窗口取消。取消或失败不算完成交付，应查看错误提示并检查输出。

导出使用 Python、PyAV、图像读取及编码组件。输出按指定帧率编码，不承诺保留 VFR 素材原有的可变帧间隔，也不是原文件的无损封装复制。需要 Alpha 时，应同时确认源素材、编码和目标软件支持 Alpha。

EXR 等浮点图像进入常规视频前需要转换到显示范围；视频不能保存原始 EXR 的全部浮点精度和任意数据通道。正式交付还应核对音轨、帧范围和目标软件兼容性。

A/B 合成视频

  1. 加载 A、B 两段素材，在查看器中设置横排、竖排、划像、叠加或差异对比。
  2. 选择“文件 → 导出 → 导出 A/B 对比视频…”。
  3. 选择当前 A/B 入出点范围或 A 的完整范围，核对输出尺寸、编码和保存位置。
  4. 选择 A、B 或不导出声音，确认后等待完成；处理中可以取消。

合成视频采用 A 的帧率输出，B 按相应时间戳取帧，超出 B 有效范围显示黑帧。ProRes HQ 使用 MOV；H.264/H.265 使用 MP4。未加载 B、非 RGB 显示、不能完整导出的自定义 LUT 或其他颜色设置会明确提示，请先处理提示再导出。

录屏

  1. 打开“窗口 → 录屏…”。面板默认关闭，打开后才读取来源和设备列表，不会自动开始录制。
  2. 默认使用“桌面 / 显示器（整屏）”，录制所选显示器上的所有应用和桌面；切换应用或最小化 CGPlay 后仍会继续。单显示器自动选中，多显示器请在来源列表选择。也可改选“播放器画面”或“指定窗口”，需要时刷新来源和声音设备。
  3. 选择原始分辨率，或 720p、1080p、2K（2560 × 1440）、4K、8K（7680 × 4320）；帧率可选 24、25、30、50、60、90、120 FPS。再选择一个尚不存在的 MP4 文件名。
  4. 按需勾选系统声音和麦克风，并选择具体设备。两者可独立调整 0–200% 音量和静音；声音混为一个 AAC 音轨。
  5. 点击“开始录制”，使用“暂停 / 继续录制”控制录屏，结束时点击“停止并保存”。暂停录屏不改变播放器的播放状态。
  6. 等待“已保存”。保存期间关闭窗口会先等待录像收尾；录制或保存未结束时请先完成该任务，再安装更新。

录制先写 MKV，结束后校验并保存 MP4。异常停止时面板会显示可复制的恢复记录和录像路径；保留两者，使用“恢复已有录像…”选择恢复记录并另存为新的 MP4。旧目标不会被覆盖；恢复成功后仍保留 MKV 与恢复记录，确认最终文件正常后可自行归档。

原始分辨率使用所选屏幕、窗口或播放器显示区域的实际像素尺寸，宽度向上补齐到 4 的倍数、高度向上补齐到偶数像素，不等同于原视频文件的分辨率。最高支持 8K / 120 FPS；当前使用 H.264 CPU 编码，面板显示实际编码输出帧率和渲染、编码跳帧数。高档位能否流畅录制取决于设备性能，掉帧时请降低分辨率或帧率。当前仅支持 Windows 的 SDR 录屏，音频为 AAC，不支持 HDR 录制。播放器区域包含当时显示的字幕、批注与浮层。录制时切全屏、跨不同缩放比例屏幕或来源尺寸变化会停止并保留录像；调整好窗口后重新开始。窗口关闭、最小化或设备失效时应查看提示，不把停止状态当作仍在录制。摄像头、直播和 OBS 插件不在本版范围内。

缓存与性能设置

内存预算和读取范围会应用到实际播放器。设置中可选择缩略图磁盘缓存位置、容量并查看使用量；自动清理只处理已标记的 CGPlay 缩略图目录。更换位置不会迁移或删除旧缓存，播放中仍使用旧位置的任务可以完成。正在使用的缓存受保护，实际使用量可暂时高于配额。

当前播放后端使用软件解码；设置会如实显示能力，不把选择某个硬件名称当作已经开启硬解。未测量的响度显示“未测量”。

10. AI 工作台

工作台在每次启动时默认关闭，需要时从“视图 → AI 工作台”（Ctrl+Shift+A）打开，首次打开时才加载界面。工作台可配置服务商、API Key、API 地址、模型、字幕管线，并提供连接测试及诊断。

界面中的 Qwen / DashScope、MiMo、Gemini、OpenAI-compatible 等选项是接入路线；实际文字、图像、语音能力取决于具体模型、接口和账户权限，并非每个模型都支持全部功能。

11. RVLite Codex 工作台

Codex 工作台默认关闭，从“视图 → Codex 工作台”打开时按需加载；旧布局不会在启动后自动将它弹出。Full 包含 Codex CLI/app-server 运行时；调用模型仍需工作台支持的登录或 API 配置、账户权限和网络，不会因安装 Full 自动获得模型使用额度。

  1. 按提示完成服务配置，选择允许操作的项目目录。
  2. 选择可用模型、推理等级和权限模式。
  3. 描述任务；需要审看片段时可使用当前画面和媒体信息作为上下文。
  4. 涉及文件修改、终端、Git 或外部工具时，核对项目路径和权限提示。

可用工具包括项目文件、搜索、终端、审片信息、画面和成果处理等；以当前工作台显示的能力为准。外部应用、插件或账户服务需另外配置。运行时缺失时可用 Full 修复安装。

12. API 配置方法

  1. 打开“视图 → AI 工作台”。
  2. 选择服务提供方 / 协议，填写对应 API Key、Base URL 和模型。
  3. 刷新服务端模型列表并选择模型；未列出的新模型可手动填写精确的模型 ID。测试连接，成功后保存配置；更换模型或地址后重新验证。
  4. 字幕相关配置还需按界面点击“保存字幕管线”；需要语音识别时测试对应 ASR 接口。
任务 必要条件
翻译已有字幕 可用的文本翻译服务
从无字幕视频的声音生成字幕 可用的语音识别服务，再按需翻译
识别烧录在画面上的硬字幕 可用本地 OCR 组件 / 模型，或支持图像的在线服务
查找在线参考字幕 配置可用的在线字幕来源
Codex 项目任务 工作台支持的模型连接、项目权限和所需工具

Base URL、模型名和协议以所选服务商当前文档为准。CGPlay 不附赠 API Key 或调用额度。断网、欠费、区域限制、模型无权限或接口不兼容时，对应在线能力不可用。

Full 不保证所有 OCR 后端与模型都已齐备；本地 OCR 依赖须可用。反馈问题时不要公开密钥。在线处理可能将相关字幕、音频片段或画面发送到配置的服务，请按素材权限使用。

13. 实时字幕与翻译

通过播放栏或“视图 → 字幕翻译”（Ctrl+Shift+T）控制显示，按需要选择快速或高质量模式。

快速模式

以边播边生成可用字幕为目标，优先复用缓存。字幕速度取决于素材、服务和网络，不能保证即时完成。没有当前有效字幕时不会用进度文字持续遮住画面。

高质量模式

结合可用的本地 / 同名 / 嵌入字幕、参考字幕、硬字幕 OCR 和语音识别进行增强。可能先预缓冲一段内容；可按界面提示使用快速结果继续观看。增强不可用时尝试回退已有结果，没有可用结果的片段仍可能无字幕。

字幕缓存通常保存在媒体旁的 CGPlay_Translations 目录。字幕来源、画面清晰度、对白质量和模型能力都会影响结果；重要交付需人工校对。

14. 硬字幕显示

对于画面已有烧录字幕的视频，翻译叠层会调整显示位置，减少与原字幕重叠；没有有效字幕时隐藏空叠层。

如仍看不到翻译，依次检查翻译开关、当前片段是否有有效字幕、生成任务是否完成、API / OCR 环境是否可用。不要将“翻译开关已打开”视为字幕已经生成。

15. 组件、更新与安装维护

  • 启动后默认在后台检查 GitHub 最新正式版，持续运行期间每天检查一次，不阻塞播放。
  • 发现新版后点击状态栏提示查看更新说明并下载；“帮助 → 检查版本更新”可随时手动检查。
  • 下载窗口显示进度并支持取消。大小和 SHA-256 校验通过后，选择“关闭并安装”；安装程序会等播放器退出后启动。
  • 设置的“软件维护”区域可以关闭“启动时自动检查更新”。
  • “帮助 → 检查缺失组件”查看组件状态，并按提示处理。
  • 1.0.7.11 及更早版本仍可能读取旧更新镜像，请使用第 1 节直链先手动安装一次 1.0.8，之后即可使用新的自动更新通道。
  • 更新或修复安装前关闭播放器及 QuickLook，安装后从“帮助 → 关于 CGPlay”核对版本。
  • 组件下载需要网络，可下载内容取决于更新源；下载某个组件成功不代表所有 AI 环境均已配齐。

16. 插件与运行环境

播放器集成播放、批注、OCIO、OTIO、AI 字幕、Codex 与 QuickLook 等模块。不同组件分别依赖解码器、Python 包、模型或外部服务。

基础播放、审片与在线 AI 的环境需求不同；先确认具体失败功能的提示，再检查对应组件。开源代码和构建说明见 项目首页。

18. QuickLook 与资源管理器缩略图

QuickLook 快速预览

启动 CGPlayQuickLook.exe 后，它会驻留系统托盘。在 Windows 资源管理器选中支持的媒体，按 Space 预览，Esc 关闭。完整批注、对比、字幕和导出请打开主程序。

视频缩略图

  1. 安装本版 Full，确保缩略图组件已安装。也可在“视图 → 自定义工作区”的“默认播放器与文件关联”中勾选格式并点击“应用关联”。
  2. 在资源管理器切换到中图标、大图标或超大图标；在文件夹选项的“查看”页取消“始终显示图标，从不显示缩略图”。
  3. 返回文件夹刷新并等待生成。若仍显示旧图标，可关闭后重新打开文件夹；Windows 的旧缩略图缓存也可能需要刷新。

缩略图显示可解码视频中的画面。文件编码、文件完整性、组件注册和 Windows 设置都会影响结果，不保证每个扩展名或编码均可生成。它与 QuickLook 预览、播放列表卡片属于不同入口。

“应用关联”登记格式及缩略图支持，不等于 Windows 已选择 CGPlay 为默认播放器。需要改变默认打开方式时，点击“打开 CGPlay 默认应用页”，按系统提示确认。

19. 常见问题与反馈

  • 安装提示未知发布者： 当前安装包未签名，请从本页 GitHub Release 下载，并核对发布信息。
  • 某个文件不能播放： 记录容器、编码和报错；同扩展名可能包含不同编码，先检查文件是否完整。
  • 导出失败： 查看进度窗口或错误提示，确认输出目录可写及相关组件存在，先用短范围重试。
  • AI 或字幕无结果： 分别检查模型协议、账户权限、额度、网络及 OCR / ASR 依赖，已有字幕翻译和语音识别不是同一服务。
  • 默认播放器没有改变： 到 Windows 默认应用页确认；登记文件关联不会绕过系统的用户默认选择。
  • 反馈问题： 使用“帮助 → 联系方式 / 反馈 Bug”，或到 GitHub Issues 提供版本、操作步骤、报错和可公开的素材特征；不要附上 API Key 或保密素材。
