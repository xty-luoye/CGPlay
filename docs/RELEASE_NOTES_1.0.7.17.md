# CGPlay 1.0.7.17 更新说明

发布日期：2026-10-13

本版修复 I / O 设置 A/B 入出点不响应的问题，并改善长视频中短循环区间的可见性。复现确认：播放列表吞键也会影响短视频和 EXR，并非只在一小时视频中发生。

- 修复播放列表获得焦点时，I / O 被列表吞掉、无法设置入点和出点的问题；清除入出点快捷键也保持可用。
- 时间轴增加清晰的 A / B 时间码，解决长视频中短循环区间过窄、标记被播放指针遮住的问题。
- 当 A 不早于 B 时显示提示，清除入出点或关闭媒体后同步清除显示。
- 保留全屏、播放中打点、快捷键改绑/禁用和文本输入行为，按住快捷键不会重复打点。

## 使用方法

按 I 设置 A（入点），按 O 设置 B（出点）；A 早于 B 时循环播放该区间。时间轴左下会显示两个时间值。Alt+I / Alt+O 分别清除入点 / 出点。文本框获得焦点时，I / O 仍正常输入文字。

本次 A/B 指时间区间循环；双素材 A/B 对比功能保持不变。

## 下载与安装

- Windows x64 完整版：[CGPlay_Setup_1.0.7.17_full.exe](https://github.com/xty-luoye/CGPlay/releases/download/v1.0.7.17/CGPlay_Setup_1.0.7.17_full.exe)
- 安装前关闭 CGPlay 和 QuickLook，安装后在“帮助 → 关于 CGPlay”确认 1.0.7.17。
- 1.0.7.12 及以上版本可通过内置更新入口获取新版，更早版本建议手动下载安装。
- 完整版包含运行组件；云端 AI 仍需自己的账户、API 或模型配置。

## 验证范围

生成带音频的一小时视频、短视频和从 1001 起始的 EXR 序列，修复版通过 102 项入出点专项检查、27 项全屏回归和 7 项命令契约检查；发布前对安装包提取出的程序复核上述入出点与全屏行为，并检查版本、依赖、载荷和摘要。自动化均在后台运行，可见窗口为 0。

本版没有修改解码、缓存和播放循环边界算法；未使用用户原始视频，不新增桌面全屏呈现性能结论。
