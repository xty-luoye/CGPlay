# CGPlay 使用说明（v1.0.7）

更新日期：2026-07-13

本文面向 CGPlay 普通用户，说明安装、播放、审片、批注、导出、字幕翻译、LUT/OCIO、QuickLook 和 RVLite Codex 工作台的使用方法。当前版本号为 `1.0.7`。

## 0. 新用户快速上手

| 步骤 | 怎么做 | 结果 |
|---|---|---|
| 1. 安装 | 双击 Full 或 Lite 安装包，根据提示完成安装。 | 桌面或开始菜单中出现 CGPlay。 |
| 2. 打开素材 | 启动 CGPlay 后，把视频或图片序列拖入窗口，或使用顶部菜单“文件 / 打开”。 | 素材出现在播放视口和播放列表中。 |
| 3. 播放审看 | 用空格播放/暂停，用左右方向键逐帧检查，用鼠标滚轮缩放画面。 | 可以快速检查画面、帧号、时间码和声音。 |
| 4. 批注反馈 | 打开批注工具栏，选择箭头、矩形、文字或自由绘制，在画面上标注问题。 | 批注会绑定到当前帧，可在 Review 面板中查看。 |
| 5. 字幕翻译 | 先在“AI 工作台”填写 API，再在播放栏打开翻译开关。 | 播放器会生成并显示中文字幕。 |
| 6. 导出交付 | 使用“导出视频”“导出带批注视频”或“HTML 报告”。 | 可输出给导演、客户或团队成员查看。 |
| 7. Codex 工作台 | 在右侧打开 RVLite Codex 工作台，选择项目后直接提问或调用工具。 | 可读取当前画面、项目文件和审片上下文。 |

## 1. 版本与安装包

当前已生成两个安装包：

| 类型 | 文件名 | 说明 |
|---|---|---|
| 完整版 Full | `CGPlay_Setup_1.0.7_full.exe` | 推荐版本。内置 Codex CLI、FFmpeg、Python、Qt WebEngine、导出与 AI 运行环境，可跨电脑离线使用。 |
| 精简版 Lite | `CGPlay_Setup_1.0.7_lite.exe` | 体积更小，适合基础播放；部分导出、AI 和 Codex 能力需要后续补齐组件。 |

主程序：

```text
CGPlay.exe
```

当前提供 Full 与 Lite 两种安装形态，可根据部署环境选择完整组件包或轻量安装包。

### 怎么选

- 第一次安装、跨电脑使用或需要完整 Codex/导出/AI 功能时，使用 Full。
- 只需要基础播放、体积要小、后续可以在线补组件时，使用 Lite。
- 如果某些导出、AI 或运行组件缺失，可在播放器内使用组件更新功能补齐。

## 2. 核心定位

CGPlay 是面向审片、动画、VFX、合成和字幕检查流程的专业播放器，核心播放链路基于 `Qt6 + OpenGL + tlRender`，同时集成批注、A/B 对比、播放列表、OTIO、OCIO、完整视频导出、字幕翻译和 RVLite Codex 工作台。

适用场景包括：

- 动画、影视、合成镜头审片。
- EXR/DPX/视频素材播放检查。
- Shot 列表管理、状态标记、批注反馈。
- A/B 版本对比和差异检查。
- 本地/嵌入/硬字幕/无字幕视频的字幕翻译与高质量辅助检查。
- 带批注视频、HTML 审片报告和 OTIO 交付。

## 3. 播放与媒体支持

播放器支持常见审片素材和视频文件：

- 图像序列：`EXR`、`DPX`、`TIFF`、`PNG`、`JPG`。
- 视频容器：`MOV`、`MP4`、`MXF`、`MKV`、`AVI`、`WebM` 等。
- 时间线：`OTIO` 导入/导出。
- 导出：`MP4`、`MOV`，支持 H.264、H.265、ProRes 等编码路径。

播放控制能力：

- 播放/暂停、停止、正放、倒放。
- 单帧前进/后退、快速跳帧、首帧/尾帧跳转。
- 帧号、时间码、FPS 显示。
- 循环播放、入点/出点、A-B 范围审看。
- 底部倍速菜单支持 `0.25x`、`0.5x`、`0.75x`、`1x`、`1.25x`、`1.5x`、`2x`、`4x`、`8x`。
- 音量、静音、音频设备/同步相关设置。
- 状态栏显示当前帧、FPS、解码器、编码、分辨率、缩放和 OCIO 状态。

### 怎么用

- 打开素材：点击顶部菜单“文件 / 打开”，或直接把文件拖入播放器窗口。
- 播放控制：点击底部播放栏按钮，或使用 `Space`、`J`、`K`、`L`。
- 逐帧检查：使用左右方向键；需要快速跳帧时使用 `Shift+Left` / `Shift+Right`。
- 设置循环：用播放栏或快捷键设置入点/出点，再开启循环播放。

## 4. 视图与窗口

视图功能包括：

- 适应窗口、1:1 像素显示、缩放、平移。
- 全屏播放，退出全屏后恢复面板布局。
- 深色审片界面和可停靠面板布局。
- 左右面板、播放栏、顶部菜单和状态栏协同显示。
- 多窗口能力，每个窗口可保持独立播放状态，同时共享部分资源管理器。

### 怎么用

- 缩放画面：鼠标滚轮缩放。
- 平移画面：按住鼠标中键拖动，或使用视图平移操作。
- 适应窗口：按 `F`。
- 1:1 查看像素：按 `1`。
- 全屏审看：按 `F11`，退出全屏按 `Esc`。

## 5. 播放列表与 Shot 管理

播放列表面板支持：

- 拖拽或打开文件加入列表。
- Shot 卡片显示缩略图、文件名、格式、分辨率、帧率、时长等信息。
- 状态颜色标记，用于区分待审、通过、修改、问题等审片状态。
- 搜索、过滤、排序。
- 快速把素材设置为 A/B 对比源。
- OTIO 导入/导出，便于和剪辑/审片时间线衔接。

### 怎么用

- 添加素材：把多个文件拖入播放列表，或从“文件 / 打开”批量选择。
- 切换镜头：点击播放列表中的 Shot 卡片。
- 查找素材：在播放列表搜索框输入文件名、格式或状态关键词。
- 标记状态：在 Shot 卡片或 Review 面板中给镜头设置审片状态。
- 导入剪辑线：使用 OTIO 导入，把剪辑时间线转换成审看片段列表。

## 6. A/B 对比

A/B 对比工具栏支持多种检查方式：

| 模式 | 用途 |
|---|---|
| A | 只看 A 源。 |
| B | 只看 B 源。 |
| Wipe | 划像对比，可调划像位置和角度。 |
| Overlay | 叠加对比，可调混合比例。 |
| Difference | 差异对比，用于查找画面变化。 |
| Horizontal | 水平分割对比。 |
| Vertical | 垂直分割对比。 |
| Tile | 平铺对比。 |

其他能力：

- 支持拖放设置 A/B。
- 支持自动清除 B 源。
- 支持快捷键切换主要对比模式。

### 怎么用

- 先打开 A 版本素材。
- 把 B 版本拖到 A/B 对比区域，或在播放列表中指定为 B 源。
- 在对比工具栏选择 Wipe、Overlay、Difference、Horizontal、Vertical 或 Tile。
- 需要检查细节时，使用划像位置、叠加比例等滑块调节对比效果。
- 常用快捷键：`A`、`B`、`W`、`N`、`D`、`H`、`V`。

## 7. 批注与审片

批注工具包括：

- 选择工具。
- 箭头。
- 矩形。
- 圆形。
- 文本。
- 自由绘制。
- 点标记。
- 颜色预设和自定义颜色。

审片数据能力：

- 批注绑定到具体帧。
- 支持撤销/重做。
- 自动保存到 `.review.json`。
- Review 面板可按帧浏览、搜索、过滤、排序、跳转和删除批注。
- 支持审片状态记录、备注和元数据查看。
- 支持导出 JSON、HTML 审片报告和带批注视频。

### 怎么用

- 打开素材并定位到需要反馈的帧。
- 在批注工具栏选择箭头、矩形、圆形、文字或自由绘制工具。
- 直接在画面上绘制或输入文字说明。
- 在 Review 面板中查看所有批注、跳转到对应帧、修改状态或删除批注。
- 交付时可导出 HTML 审片报告、批注 JSON 或带批注视频。

## 8. 色彩管理

OCIO 色彩管理能力包括：

- 支持启用/禁用 OCIO。
- 支持内置 ACES 配置。
- 支持加载外部 `.ocio` 配置。
- 查看器顶部 `LUT` 按钮可直接打开 LUT/OCIO 设置，`OCIO` 按钮负责启用或关闭色彩管理。
- 支持输入色彩空间、显示、视图、曝光、伽马等设置。
- 导出带批注视频时可应用 CPU 色彩处理路径。

## 9. 导出功能

当前导出能力：

- 批注 JSON 导出。
- HTML 审片报告导出。
- Clean 视频导出。
- Annotated 带批注视频导出。
- OTIO 时间线导入/导出。

视频导出由 Python 工具链参与，使用 OpenImageIO、PyAV、numpy、Pillow 等组件处理帧读取、色调映射和编码。视频导出支持完整帧范围，不再限制为单帧；可按整个媒体、入出点或导出对话框中的帧范围输出。

### 怎么用

- 色彩管理：从顶部菜单“颜色”进入，选择是否启用 OCIO，并设置输入/显示/视图。
- 导出普通视频：使用“导出视频”，选择输出格式、编码和范围。
- 导出批注视频：使用“导出带批注视频”，把画面批注烧录进视频。
- 导出审片报告：使用 HTML 报告，适合发给不安装播放器的人查看。
- 导入/导出时间线：使用 OTIO，把 CGPlay 和剪辑、合成流程衔接起来。

## 10. AI 工作台

AI 工作台提供集中配置和诊断入口：

- AI 模型与服务商设置。
- OpenAI-compatible / MiMo / Qwen-DashScope 等路线配置。
- API key、base URL、模型名配置。
- 模型发现、连接验证和测试。
- ASR 与字幕翻译相关设置。
- 字幕源语言、目标语言、在线字幕/参考源相关配置。
- Qwen ASR 测试入口。
- 导出诊断报告。

当前支持的主要模型路线：

| 能力 | 当前说明 |
|---|---|
| Qwen / DashScope | 支持 Qwen 文本翻译和 Qwen ASR，可用于字幕识别、字幕翻译和内容处理。 |
| MiMo | 支持 MiMo 相关配置，可用于语音识别、字幕翻译和高质量字幕流程。 |
| Gemini | 支持 Gemini 系列模型接入，可用于 AI 工作台、文本处理和字幕翻译。 |
| GPT-4o | 支持 GPT-4o / OpenAI-compatible 路线，可用于 AI 工作台、字幕翻译、文本修正和高质量增强。 |
| 独立配置 | 不同模型服务可分别保存 key、地址和模型配置，便于按任务切换。 |
| 连接检查 | 提供模型连接验证和诊断信息，方便确认当前 AI 服务是否可用。 |

## 11. RVLite Codex 工作台

播放器右侧的 RVLite Codex 工作台使用无界面的 Codex CLI/app-server 运行核心，不是 Codex 桌面应用。完整版已经内置该运行时。

主要能力包括：

- 读取播放器当前画面并作为同一轮对话的图像上下文。
- 读取和修改当前项目内文件、搜索文本、运行受控进程、登记输出成果。
- 使用播放器媒体元数据、导出、审片包、音频分析和 HDR 信息工具。
- 管理 Codex 会话、模型、推理等级、权限模式、MCP、Skills、插件和 Apps。
- 使用项目终端、Git Diff、后台任务以及本地多代理编排。
- 将生成的图片或成果保存、复制或导入播放器。

### 怎么用

1. 打开右侧 RVLite Codex 工作台。
2. 点击项目按钮，选择允许 Codex 操作的项目目录。
3. 选择模型、推理等级和权限模式。
4. 在输入框中描述任务；需要分析播放器画面时可直接说“分析当前画面”。
5. 执行文件修改、终端、Git 或外部软件操作前，检查当前权限模式和项目路径。

如果显示“内置 Codex CLI 运行时缺失或不可运行”，请使用 CGPlay 完整版修复或重新安装，不需要安装 Codex 桌面应用。

## 12. API 配置方法

字幕翻译、语音识别、AI 文本处理和高质量字幕功能都需要先在 AI 工作台中配置 API。

### 入口在哪里

1. 打开 CGPlay。
2. 点击顶部菜单“窗口”。
3. 打开“AI 工作台”。
4. 进入设置区域，找到“服务提供方”“API Key”“Base URL / API 地址”“模型”。
5. 填写后点击“测试连接”，成功后点击“保存配置”。

### 通用填写规则

| 字段 | 填写内容 | 说明 |
|---|---|---|
| 服务提供方 | 选择 Qwen / MiMo / Gemini / OpenAI-compatible 等。 | 决定使用哪一家模型服务。 |
| API Key | 填写对应服务商后台生成的密钥。 | 密钥只需要填一次；以后可以留空继续使用已保存密钥。 |
| Base URL / API 地址 | 填写服务商提供的接口地址。 | OpenAI-compatible 服务通常填写到 `/v1` 这一层即可。 |
| 模型 | 填写或选择要使用的模型名。 | 例如 GPT-4o、Gemini、Qwen 或 MiMo 对应模型。 |
| 测试连接 | 点击按钮测试。 | 看到“连接测试通过”后，再保存配置。 |

### 常见 API 填写示例

| 模型路线 | 适合用途 | Base URL 示例 | 模型示例 |
|---|---|---|---|
| Qwen / DashScope | 字幕翻译、语音识别、文本处理。 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus`、`qwen3-asr-flash` |
| MiMo | 语音识别、字幕翻译、高质量字幕流程。 | 填写 MiMo 后台提供的 API 地址。 | 填写 MiMo 后台支持的模型名。 |
| Gemini | AI 工作台、文本处理、字幕翻译。 | `https://generativelanguage.googleapis.com` | 填写 Gemini 系列模型名。 |
| GPT-4o / OpenAI-compatible | AI 工作台、字幕翻译、文本修正、高质量增强。 | `https://api.openai.com` 或兼容服务地址。 | `gpt-4o` |

### 字幕相关 API 怎么填

| 位置 | 用途 | 怎么填 |
|---|---|---|
| 语音识别 API 协议 | 无字幕视频、音频听写、自动生成源字幕。 | 选择 Qwen3-ASR / DashScope、Gemini 或 OpenAI transcription，并填写对应 API Key、Base URL、模型。 |
| 工作台 API | 搜字幕、读画面字、翻译、修复、融合。 | 选择 Qwen / DashScope 或 OpenAI-compatible，再填写文本模型 API。 |
| 在线字幕 API | 高质量模式下查找参考字幕。 | 如果有在线字幕服务，填写它的 API Key 和接口地址；没有则可以不填。 |
| 保存字幕管线 | 保存上述字幕相关配置。 | 填完后点击“保存字幕管线”。 |
| 测试语音识别 API | 确认 ASR 能否正常工作。 | 点击“测试语音识别 API”，成功后再打开视频使用翻译。 |

给他人配置时，建议先填“工作台 API”，再填“语音识别 API”。如果只翻译已有字幕，通常工作台 API 就能完成；如果视频没有字幕，才需要语音识别 API。

## 13. 实时字幕与翻译

播放栏提供字幕/翻译开关，并支持快速模式和高质量/手动增强模式。

### 13.1 快速字幕模式

快速模式目标是“边播边出字幕”，适合预览、审片和快速理解视频内容。

快速模式规则：

- 不暂停播放等待字幕。
- 优先使用轻量识别和翻译流程，尽快显示字幕。
- 生成的字幕可复用，重复播放时可更快加载。
- 无对白或无有效当前字幕时，字幕 overlay 会保持干净，不用进度文字遮挡画面。

生成字幕默认输出目录：

```text
CGPlay_Translations
```

### 13.2 字幕来源选择

高质量字幕会优先使用更可靠的字幕来源：

1. 本地、同名、嵌入式、外部文本字幕。
2. 已配置的在线或参考字幕来源。
3. 画面内硬字幕 OCR。
4. 音频语音识别。
5. 快速字幕结果作为兜底显示。

本地/嵌入/外部字幕会优先于音频识别；硬字幕视频可使用 OCR 提取画面内文字；无字幕视频可使用语音识别生成字幕。

### 13.3 高质量字幕模式

高质量/手动增强模式用于追求更准确的字幕来源和更好的翻译质量，特点是：

- 可对硬字幕视频启用 OCR，提取画面内字幕内容。
- 可对无字幕视频使用更长窗口的语音识别，提升上下文完整度。
- 可使用本地/嵌入/外部字幕作为优先源。
- 可使用在线或参考字幕来源辅助校对。
- 根据可用来源自动选择更可靠的字幕文本。
- 在字幕缺失或识别不完整时自动回到可用结果，保证播放时仍有字幕参考。

注意：字幕识别和翻译效果会受到音频清晰度、字幕画质、模型能力和网络状态影响。高质量模式适合对重要片段进行更精细的字幕处理。

### 怎么用

- 先按“API 配置方法”填写工作台 API 和语音识别 API。
- 打开需要翻译的视频。
- 在播放栏点击翻译开关。
- 普通预览选择快速模式；重要片段或硬字幕视频选择高质量模式。
- 如果视频自带字幕或旁边有同名字幕文件，播放器会优先使用文字字幕进行翻译。
- 如果视频没有字幕，播放器会调用语音识别生成字幕后再翻译。

## 14. 硬字幕显示优化

对于画面底部已有烧录字幕的视频，生成的中文字幕 overlay 会抬高显示，避免和原视频硬字幕重叠，防止“翻译已生成但看起来没显示”的情况。

同时：

- 没有当前有效字幕时隐藏 overlay。
- 不显示宽大的无文字黑底条。
- 不用中央“正在生成字幕”遮挡画面。
- 正常对白 cue 仍保持可见。

## 15. 组件、更新与安装维护

## 16. 插件与架构能力

- 播放核心和 tlRender 封装。
- 批注系统。

## 18. QuickLook

- 安装后启动 `CGPlayQuickLook.exe`，它会驻留在系统托盘。
- 在 Windows 资源管理器中选中支持的视频或图像序列，按 `Space` 打开预览。
- 按 `Esc` 关闭预览；完整批注、对比、字幕与导出请打开 CGPlay 主程序。

## 19. 使用注意事项

- 安装包当前未签名，系统可能提示未知发布者。
- 完整版体积较大，因为它真实包含 Codex CLI、Python、FFmpeg 和 WebEngine 运行环境。
- AI 字幕和翻译质量会受到模型服务、API key、网络状态和素材质量影响。
- 在线字幕和参考字幕功能需要配置可用的服务或数据来源。
- 硬字幕 OCR 效果会受到画面清晰度、字体、遮挡和压缩噪声影响。
- 不同模型在语音识别、翻译和文本润色上的表现可能不同，建议根据素材类型选择 Qwen、MiMo、Gemini 或 GPT-4o 等模型路线。
